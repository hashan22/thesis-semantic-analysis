# Semantic Similarity and Sentiment Analysis of AI-Generated Narratives

## Overview

This repository contains the Python code developed for my master's thesis, *Comparing AI Narratives of Tragedy: Semantic Similarity Analysis and Prompt Engineering in Large Language Models*.

The project analyses AI-generated narratives using semantic similarity, sentiment analysis, and emotion analysis.

## Methods and Tools

- Python
- Sentence Transformers (`all-MiniLM-L6-v2`)
- Cosine similarity
- NLTK VADER sentiment analysis
- NRC emotion lexicon analysis
- Pandas for data processing and CSV output

## Project Structure

- `semantic_analysis.py` — main analysis script
- `Prompts/` — input files, if included in the shared version
- `requirements.txt` — Python dependencies
- `README.md` — project documentation

## Running the Code

1. Install Python and the dependencies listed in `requirements.txt`.
2. Place the required input files in the expected folder structure.
3. Run the analysis script.
4. The script generates a CSV containing the analysis results.

## Reproducibility

The reported results should be interpreted in relation to the exact code version, input texts, model settings, and analysis configuration used to produce them. See the repository history or releases for version information.
