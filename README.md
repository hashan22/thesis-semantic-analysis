# Comparing AI Narratives of Tragedy: Semantic Similarity, Sentiment and Emotion Analysis

## Overview

This repository contains the source code and research materials for a thesis investigating AI-generated narratives of tragedy using semantic similarity, sentiment analysis, and emotion analysis.

The study compares narratives generated by ChatGPT and Mistral against a baseline reference narrative, examining how different prompts influence semantic similarity and emotional and sentiment-related characteristics.

The research uses the 2020 Vienna terrorist attack as a case study to explore how large language models represent a real-world tragedy across different prompting conditions.

## Research Objectives

- Measure semantic similarity between AI-generated narratives and a baseline reference narrative.
- Analyse sentiment polarity in generated narratives.
- Examine emotional categories expressed in the narratives.
- Investigate how prompt engineering influences narrative similarity, sentiment, and emotion.
- Compare the outputs of ChatGPT and Mistral using a consistent analytical pipeline.

## Models and Tools

The research pipeline uses the following tools and libraries:

- **ChatGPT:** AI-generated narrative responses.
- **Mistral:** AI-generated narrative responses.
- **Python:** Research implementation and data processing.
- **Pandas:** Data organisation and CSV output.
- **NLTK VADER:** Sentiment polarity analysis.
- **NRCLex:** Emotion lexicon-based analysis.
- **Sentence Transformers:** Semantic embeddings and similarity calculations.
- **all-MiniLM-L6-v2:** Sentence embedding model used for semantic similarity analysis.

Model outputs are analysed as research data. The analysis does not imply that AI-generated narratives are factual or that sentiment and emotion lexicons fully capture human emotional experience.

The study uses 80 prompts organised into five categories:

| Category | Number of prompts |
|---|---:|
| Role-based prompts | 20 |
| Temporal prompts | 15 |
| Causality and motivation prompts | 15 |
| Media comparison prompts | 10 |
| Ethics, trauma and collective memory prompts | 20 |
| **Total** | **80** |

The prompts are designed to investigate different narrative dimensions and assess how prompt formulation affects model responses.

## Methodology

### 1. Data preparation

The generated narratives and baseline reference text are loaded and prepared for analysis. The text is processed to ensure that it can be passed consistently to the semantic similarity and sentiment analysis components.

### 2. Semantic similarity analysis

Sentence Transformers generate vector embeddings for the texts. Cosine similarity is then used to estimate the semantic similarity between each AI-generated narrative and the baseline reference.

The similarity scores represent embedding-based semantic relatedness, not factual correctness or the quality of a narrative.

### 3. Sentiment analysis

The VADER sentiment analyser calculates sentiment polarity scores, including positive, negative, neutral, and compound scores.

### 4. Emotion analysis

NRCLex is used to estimate the presence of lexicon-associated emotional categories in the narratives. These outputs are interpreted as lexical indicators rather than definitive measurements of a model's emotional state or a reader's psychological response.

### 5. Results export

The analysis results are organised into a Pandas DataFrame and exported to CSV for further examination, comparison, and reporting.

## Installation

Python 3.10 or a compatible version is recommended, subject to the compatibility of the installed dependencies.

Clone the repository:

```bash
git clone https://github.com/hashan22/thesis-semantic-analysis.git
cd thesis-semantic-analysis
```

Create and activate a virtual environment.

**Windows (Git Bash):**

```bash
python -m venv .venv
source .venv/Scripts/activate
```

Install the dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Running the Analysis

Run the main analysis script from the repository root:

```bash
python semantic_sentiment_analysis.py
```

The script processes the configured input files and saves the analysis results to the designated CSV output file.

Before execution, verify that the input paths in the script match the actual repository structure and that all required prompt and reference files are available.

If the implementation is provided in a Jupyter notebook instead of a Python script, open the notebook and execute its cells in order after installing the dependencies.

## Reproducibility and Limitations

- Results depend on the model versions, generated text, prompt wording, and preprocessing procedures used.
- Sentence embedding similarity measures semantic relatedness and should not be interpreted as a direct measure of truth or factual accuracy.
- VADER and NRCLex are lexicon-based tools and may not fully capture context, irony, cultural differences, or complex emotional meaning.
- Reproducing the study may require access to the original generated responses and reference texts.
- Model versions, package versions, and experimental settings should be documented when reporting results.

## Ethical Considerations

The study examines AI-generated narratives concerning a real terrorist attack. The analysis should be interpreted sensitively, with consideration for victims, survivors, affected communities, and the risks of misrepresentation.

The research evaluates linguistic characteristics of model-generated text and does not establish the psychological experiences of victims or survivors.
